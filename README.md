# 奶龙开饭啦！

**45 秒美食大挑战** · Windows 本地离线小游戏

看准奶龙左右摆动的方向，点击游戏区域或按空格伸出弹力舌头，将零食带回嘴里。45 秒内获得 120 美味值即挑战成功，进入奶娃变身和捧腹大笑庆祝。

## 下载与启动

1. 下载仓库中的 **奶龙开饭啦-离线版.zip**，或通过 **Code → Download ZIP** 下载完整源码。
2. 完整解压到本地文件夹。
3. 双击 **开始游戏.html**，也可双击 **一键启动游戏.cmd**。

推荐 Microsoft Edge 或 Google Chrome。无需联网、服务器、Node.js、Python 或安装游戏。请保留 `assets`、脚本、样式文件与 HTML 的相对位置。

## 操作与规则

- 鼠标点击游戏区 / 空格：出舌。
- Esc / 右上角按钮：暂停、继续；离开窗口自动暂停，回来后手动继续。
- 支持重试和音效开关。
- 奶茶 +10、炸鸡腿 +15、彩虹冰淇淋 +20、汉堡 +25。
- 苦瓜 −10，分数最低为 0，舌头打结 1 秒，期间倒计时继续。
- 食物回到嘴部才计分；超时仍在途的食物不计分。
- 每局奶茶 5、鸡腿 5、冰淇淋 4、汉堡 1–2、苦瓜 6，位置和普通食物大小随机。
