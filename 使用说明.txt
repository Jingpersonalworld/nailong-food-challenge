《奶龙开饭啦！》——45 秒美食大挑战

【开始玩】
1. 把整个压缩包解压到普通文件夹，不要直接在压缩软件里打开。
2. 双击“开始游戏.html”，或双击“一键启动游戏.cmd”。
3. 推荐使用 Microsoft Edge 或 Google Chrome。无需联网、安装或开发工具。
4. 分享给朋友时，请发送完整压缩包，不要只发送 HTML 文件。

【操作】
点击“开饭啦！”开始。舌头会自动左右摆动瞄准。
看准时机，点击游戏区域或按空格出舌；伸出与收回途中不能再次发射。
食物回到嘴部才计分。空抓或碰到边界会自动收回。
右上角可暂停、继续、重试和关闭音效；Esc 也可暂停/继续。
切换窗口或标签页会自动暂停，回来后点击“继续开吃”。

【规则】
45 秒内达到 120 美味值立即胜利，进入奶龙变奶娃和捧腹大笑庆祝。
奶茶 +10，炸鸡腿 +15，彩虹冰淇淋 +20，汉堡 +25。
每局奶茶5、鸡腿5、冰淇淋4、汉堡随机1–2、苦瓜6。
苦瓜 −10 分，分数最低为0，舌头打结1秒，打结时倒计时继续。
时间到仍未达标则挑战失败，在途食物不再计分，可以再玩一次。
每次开始/重试位置与普通食物90%–110%大小重新随机。大小不改变分数与移动速度。

【注意】
保留 assets 文件夹、core.js、game.js 和 style.css 与 HTML 的相对位置。
浏览器若禁止 JavaScript 或本地文件脚本，需使用允许执行本地 HTML 的普通浏览器。
浏览器音效需首次点击后才能播放。无官方角色配音，全部为本地程序合成音效。
画面使用透明二维图片、缩放/摇晃/渐变动画和 Canvas 舌头，不是三维骨骼动画。
可缩放浏览器窗口；狭小窗口可滚动页面。更改窗口大小不改变游戏速度。

【验证范围】
2026-10-08 在当前 Windows 电脑的 Edge 154、Chrome 154 上进行 file:// 离线测试。
详细测试记录见“验证报告.md”。未覆盖所有 Windows 10/11 设备、Firefox 或企业限制浏览器。
70% 是普通玩家熟悉操作后的难度目标，尚无足够真人试玩，不保证实际胜率。
